## n8nワークフローでの実装例

### 推奨ワークフロー構成

```
1. [Schedule Trigger] または [Manual Trigger]
   ↓
2. [Tavily Search Node]
   - Search Query: "AI stocks small cap mid cap latest news 2025"
   - または日本語: "米国株 AI 小型株 中型株 最新"
   ↓
3. [Code Node] (オプション：検索結果を整形)
   - Tavilyの結果からキーワード抽出
   - 企業名、数字、ニュース要約を抽出
   ↓
4. [OpenAI Node (ChatGPT)]
   - Model: gpt-4o-mini
   - System Message: 上記のシステムプロンプト
   - User Message: 上記のユーザープロンプト（パターンB推奨）
   ↓
5. [Twitter Node] または [HTTP Request Node]
   - 生成された投稿をX/Twitterに投稿
   ↓
6. [完了]
```

## Code Node（検索結果整形）のサンプルコード

Tavilyの検索結果を整形して、ChatGPTに渡しやすくするコードです。

```javascript
// Tavilyの検索結果を取得
const tavilyResults = $input.item.json.results;

// 最初の3件の結果を要約
let summary = "";
for (let i = 0; i < Math.min(3, tavilyResults.length); i++) {
  const result = tavilyResults[i];
  summary += `【情報${i + 1}】\n`;
  summary += `タイトル: ${result.title}\n`;
  summary += `概要: ${result.content}\n`;
  summary += `URL: ${result.url}\n\n`;
}

// ChatGPTに渡す形式で出力
return {
  json: {
    tavily_summary: summary,
    result_count: tavilyResults.length,
    search_date: new Date().toISOString().split('T')[0]
  }
};
```

## 文字数チェック用Code Node（投稿前）

ChatGPTが140文字超過する場合があるので、チェック用のノードを追加することを推奨します。

```javascript
const tweet = $input.item.json.choices[0].message.content;
const tweetLength = tweet.length;

// 140文字以内かチェック
if (tweetLength > 140) {
  // 140文字を超えている場合、切り詰める
  const trimmedTweet = tweet.substring(0, 137) + "...";
  return {
    json: {
      tweet: trimmedTweet,
      original_length: tweetLength,
      is_trimmed: true
    }
  };
} else {
  return {
    json: {
      tweet: tweet,
      original_length: tweetLength,
      is_trimmed: false
    }
  };
}
```

## Tips：より魅力的な投稿にするコツ

### 1. Tavilyの検索クエリを工夫する

**良い検索クエリ例**：
- `"AI stocks small cap high growth 2025"`
- `"AI semiconductor stocks under $10 billion market cap"`
- `"emerging AI companies cybersecurity"`
- `"AI drug discovery biotech stocks"`

**日本語でも可**：
- `"米国株 AI 小型株 成長率"`
- `"人工知能 中型株 2025年"`

### 2. 検索結果のフィルタリング

Code Nodeで、時価総額や成長率でフィルタリングすると質が上がります。

```javascript
// 時価総額10億〜200億ドルの企業のみ抽出
const filtered = tavilyResults.filter(result => {
  const marketCap = extractMarketCap(result.content); // 独自関数
  return marketCap >= 1e9 && marketCap <= 200e9;
});
```

### 3. 投稿のバリエーションを持たせる

システムプロンプトに「投稿の型」をランダムで選ばせることも可能：

```
今回は以下の型のいずれかを使ってください（ランダムで1つ選択）：
1. 発見型：「〜を調べてみました」
2. 数字型：「〜%上昇」「時価総額〜億ドル」
3. 疑問型：「〜って知ってました？」
4. 比較型：「〜と比べて〜」
```

### 4. ハッシュタグの最適化

投稿内容に応じてハッシュタグを動的に選択させる：

```
【ハッシュタグ選択ルール】
- 必須: #米国株 #AI株
- 時価総額に応じて: #小型株（<50億ドル）または #中型株（50-200億ドル）
- セクターに応じて: #半導体株 #サイバーセキュリティ #バイオテック など
```

## トラブルシューティング

### 問題1: 140文字を頻繁に超過する

**解決策**:
- システムプロンプトに「厳守：140文字以内」を強調
- Temperature を下げる（0.5程度）
- Code Nodeで強制的に切り詰め

### 問題2: ハッシュタグが多すぎる/少なすぎる

**解決策**:
- 「ハッシュタグは必ず3個」と明確に指定
- 出力例を示す

### 問題3: アイヒモの口調になっていない

**解決策**:
- システムプロンプトに具体例を追加
- Few-shot learning: 良い例を2-3個示す
