# 自己紹介マガジン用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
noteマガジン「自己紹介」のカバーバナー画像を作成してください。
シンプルで文字が読みやすく、親しみやすいデザインにしてください。

【レイアウト】
- 左側：タイトルテキスト（シンプルな構成）
  - メインタイトル：「アイヒモの自己紹介」（大きめ、太字）
  - サブタイトル：「AIのひもを目指す20代の投資記録」（やや小さく）
- 右側：アイヒモのキャラクター（画面の約25%を占めるサイズ）
- 背景：シンプルで装飾なし

【デザイン要素】
- 背景：純白（#FFFFFF）またはごく淡いピンク（#FFF5F7）- 親しみやすさ
- テキストカラー：濃いネイビー（#1A1A2E）または黒（#000000）
- アクセント：なし、または最小限の幾何学模様（線1-2本程度）
- 装飾：最小限（複雑なグラフィックは不要）

【文字の見やすさ重視】
- タイトルは画像の左側に配置
- フォント：太字で読みやすいゴシック体
- 文字と背景のコントラスト比を高く（WCAG AAA基準）
- 余計な装飾で文字が読みにくくならないよう注意

【キャラクター：アイヒモ】
- 画像の右側に配置（画面の約25%を占めるサイズ）
- 肩より上のバストショット
- 参考画像のスタイルをそのまま維持（表情変更なし）
- タイトルとバランスよく配置
- 自己紹介マガジンなので、キャラクターの存在感を重視

【シンプルなアクセント（オプション）】
- 最小限の幾何学模様（1-2本の線、シンプルなフレームなど）
- 自己紹介を表すシンプルなアイコン（吹き出し、プロフィールカードなど）
- いずれも文字の視認性を損なわない程度

【全体の雰囲気】
- シンプルでクリーン
- 文字とキャラクターのバランスを重視
- 親しみやすく温かい印象
- 装飾は最小限、情報伝達を最優先
- アイヒモのキャラクターが主役の一つ（自己紹介なので）

【サイズ】
- 横長バナー（16:9または類似の比率）
- noteマガジンのカバー画像に適したサイズ
```

---

## カラーパレット（参考）

### メインカラー
- **背景**: `#FFFFFF`（純白）または `#FFF5F7`（ごく淡いピンク、親しみやすさ）
- **テキスト**: `#1A1A2E`（濃いネイビー）または `#000000`（黒）

### アクセントカラー（最小限使用）
- **アクセント1**: `#2C3E50`（ダークグレー）- 線やフレーム用
- **アクセント2**: `#E74C3C`（ソフトレッド）- アイコン用（オプション）

### コントラスト比
- 文字と背景のコントラスト比：21:1以上（WCAG AAA基準）

---

## デザインの優先順位

1. **文字の見やすさ**: 読みやすいサイズと配置
2. **キャラクターとのバランス**: アイヒモが画面の25%を占める
3. **親しみやすさ**: 温かく柔らかい印象
4. **シンプルさ**: 装飾は最小限
5. **一貫性**: noteマガジン全体で統一感
