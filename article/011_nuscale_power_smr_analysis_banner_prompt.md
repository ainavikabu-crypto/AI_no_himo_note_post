# NuScale Power (SMR) 銘柄分析記事 - バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
3段構成のタイトルテキストを左側に配置：
1段目（小さめ、カテゴリ表示）：「米国株 銘柄分析」
2段目（大きく、太字）：「NuScale Power (SMR)」
3段目（やや小さく、サブタイトル）：「株価65%急落の小型原子炉、2026年は復活なるか」

背景：
- 左側にテキストエリア（白または薄いグレーの背景）
- 右側・背景に企業の事業内容を表すイラスト：小型モジュール原子炉（円筒形の原子炉モジュール）、クリーンエネルギーのイメージ（緑色の電力アイコン）、データセンター（サーバーラック）を組み合わせたイラスト
- 全体的に先進的で技術的な印象

アイヒモのキャラクター：
- 右下隅に小さく配置（肩より上のバストショット）
- サイズは控えめ（バナー全体の10-15%程度）
- 参考画像のスタイルをそのまま維持（表情変更なし、明るくしない）

色調：
- メインカラー：ディープブルー、テクノロジーグリーン
- アクセント：シルバー、ホワイト
- 原子力のクリーンなイメージと先進技術を表現
```

## デザイン要素

1. **小型モジュール原子炉のビジュアル**
   - 円筒形のモジュールを3-4個並べたイラスト
   - 技術的で未来的なデザイン
   - 緑色の電力アイコンやエネルギーフローを表現

2. **AIデータセンター要素**
   - サーバーラックやデータセンターのシルエット
   - 原子炉とデータセンターをつなぐエネルギーフローのライン

3. **テキスト配置**
   - 1段目：「米国株 銘柄分析」（小さく、カテゴリ）
   - 2段目：「NuScale Power (SMR)」（目立つように、太字）
   - 3段目：「株価65%急落の小型原子炉、2026年は復活なるか」（インパクトを与えるサブタイトル）

4. **アイヒモキャラクター**
   - 右下に控えめに配置
   - 肩より上のバストショット
   - 参考画像のイメージを維持

## 使用方法

1. nanobananaにこのプロンプトを入力
2. アイヒモのキャラクター参考画像をアップロード（必須）
3. 生成されたバナー画像を記事のトップに配置
4. 画像サイズ：1200x630px推奨（note/X投稿用）

## 注意事項

- アイヒモの表情は参考画像のまま維持すること（明るくしたり、笑顔にしたりしない）
- 小型原子炉とAIデータセンターの両方を表現すること
- テクノロジー感とクリーンエネルギーのイメージを重視
- 「65%急落」という数字が目立つように配置
