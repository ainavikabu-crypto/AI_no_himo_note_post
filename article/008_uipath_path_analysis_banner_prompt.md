# バナー画像生成プロンプト

**記事**: UiPath (PATH) を調べてみた：業務自動化のリーダーが遂に黒字化達成
**作成日**: 2025年12月15日
**ツール**: nanobanana（バナナpro）

---

## 日本語プロンプト

```
横長のブログバナー画像を作成してください。

【タイトル構成】（左側に配置）
1段目：「米国株 銘柄分析」（小さめ、白色、カテゴリ表示）
2段目：「UiPath (PATH)」（大きく、太字、白色、メインタイトル）
3段目：「業務自動化のリーダーが遂に黒字化達成」（やや小さく、白色、サブタイトル）

【キャラクター】（右下隅に配置）
- アイヒモのキャラクター画像を参考にして、肩より上のバストショットを配置
- サイズは控えめにして、情報が目立つようにする
- アイヒモの表情は参考画像のイメージ通りに維持（明るくしない）

【背景イラスト】（余白に配置、控えめに）
- RPAと業務自動化を象徴するイラストを1つ追加：
  - ロボットアームがパソコンを操作している様子
  - ワークフローの自動化を示す矢印とアイコン
  - データ処理の自動化を表現
- イラストは背景に溶け込むように、タイトルの邪魔にならないように配置

【配色】
- 背景：濃紺から青緑のグラデーション（自動化、効率）
- テキスト：白色（視認性重視）
- アクセント：緑または明るい青（成長、黒字化）

【全体の雰囲気】
- プロフェッショナルで効率的なデザイン
- 業務自動化の効果を感じさせる
- 黒字化という前向きなニュースを表現
```
