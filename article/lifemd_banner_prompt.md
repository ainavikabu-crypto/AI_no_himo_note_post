# LifeMD（LFMD）記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
LifeMD（LFMD）の米国株投資分析を紹介するnote記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 銘柄分析」（小さめ、カテゴリ表示）
  - 2段目：「LifeMD (LFMD)」（大きく、太字）
  - 3段目：「遠隔医療で調整後EBITDA+254%成長」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：企業の事業内容を表すイラスト（スマホ、医師のアイコン、処方箋、配送箱など）

【デザイン要素】
- 背景：白またはライトグレーのシンプルな背景
- テキストカラー：ネイビーまたはダークグレー
- アクセント：ヘルスケア系カラー（ブルー、グリーン）を控えめに使用

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置

【企業イラスト】
- 余白に1つ追加：スマホ画面に医師アイコン、処方箋、配送箱など
- LifeMDの事業（遠隔医療プラットフォーム）が視覚的に伝わるもの

【サイズ】
- 横長バナー（16:9または類似の比率）
```
