## ステップ2：n8nにAPIを登録する

n8nにログインしたら、各APIの認証情報を登録します。

### Tavily APIの登録

1. n8nの左メニューから「Credentials」を選択
2. 「Add Credential」をクリック
3. 検索窓に「Tavily」と入力
4. 「Tavily API」を選択
5. 先ほど取得したAPIキーを入力
6. 名前を「Tavily account」に設定（ワークフローJSONと合わせるため）
7. 「Save」

### X（Twitter）APIの登録

1. 同じく「Credentials」→「Add Credential」
2. 検索窓に「Twitter」と入力
3. 「Twitter OAuth2 API」を選択
4. 以下を入力：
   - Client ID
   - Client Secret
   - OAuth Callback URL（n8nが自動生成）
5. 名前を「X n8n connect」に設定
6. 「Connect my account」をクリックして認証
7. 「Save」

### OpenAI APIの登録

1. 同じく「Credentials」→「Add Credential」
2. 検索窓に「OpenAI」と入力
3. 「OpenAI API」を選択
4. APIキーを入力
5. 名前を「OpenAi account_selfhost」に設定（ワークフローJSONと合わせるため）
6. 「Save」

**重要**: ワークフローJSONに記載されている名前と完全に一致させてください。名前が違うと、後でエラーになります。

### エラーが出た場合

#### エラー：「Credentials not found」
- 原因：認証情報のIDが正しく設定されていない
- 解決策：ステップ4をもう一度確認

#### エラー：「Rate limit exceeded」（Tavily）
- 原因：Tavilyの無料枠（月1,000回）を超過

- 原因：XのAPI権限が不足している

- 原因：ChatGPTが140文字を超える投稿を生成
- 解決策：プロンプトに「厳守：140文字以内」を追加

   - 「SOFI（SoFi Technologies, Inc.）」→「TSLA（Tesla, Inc.）」

   - 企業の説明も変更

2. 各ワークフローで銘柄を変更（SOFI、TSLA、NVDAなど）
3. 投稿時間をずらす（例：9時SOFI、12時TSLA、18時NVDA）

## トラブルシューティング

### Q1: 140文字を超える投稿が生成される

**解決策1**: プロンプトを強化
```
【重要】必ず140文字以内に収めてください。141文字以上は絶対に許可されません。
```

**解決策2**: Code Nodeで文字数チェックを追加
- 「AI Agent」と「Create Tweet」の間にCode Nodeを追加
- 140文字を超えたら自動で切り詰める処理を実装
- 詳細は私の前回記事「n8n文字数チェック完全ガイド」参照

### Q2: 検索結果が空でエラーになる

**原因**: Tavilyが関連情報を見つけられなかった

**解決策**: プロンプトにフォールバック処理を追加
```
もし最新ニュースが見つからない場合は、SOFIの基本情報（ビジネスモデル、直近の業績など）を元に投稿を作成してください。
```

### Q3: 同じ内容の投稿が続く

**原因**: Tavilyの検索結果が変わっていない

**解決策**: 検索クエリに日付を含める
```
SoFi SOFI stock news published last 24 hours
```

または、Tavilyノードの設定で「Time Range」を「day」に変更

### Q4: X APIのRate Limitエラー

**原因**: X APIの投稿回数制限（無料プランは月1,500投稿）

**解決策**:
- 1日1回に抑える
- または、X API有料プラン（Basic: $100/月）にアップグレード
