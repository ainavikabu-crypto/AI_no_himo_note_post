# 今週の振り返り記事用バナー画像生成プロンプト

## 概要

この振り返り記事用のバナー画像は、**明るくポジティブな雰囲気**を重視しています。いつもの銘柄分析記事より華やかで、祝福感のあるデザインです。

---

## nanobanana用プロンプト（日本語）

```
今週の振り返り記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「note 活動振り返り」（小さめ、カテゴリ表示）
  - 2段目：「1000PV突破！」（大きく、太字、明るく）
  - 3段目：「情報発信を続ける理由」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：ポジティブなイラスト（スキアイコン、グラフ上昇、星、いいねマークなど）

【デザイン要素】
- 背景：明るい色（ライトイエロー、クリーム色、ライトオレンジなど）
- テキストカラー：ダークグレーまたはネイビー（読みやすさ重視）
- アクセント：明るいオレンジ、ゴールド、ライトグリーンを使用
- 装飾：星やキラキラなど、祝福感のある要素を控えめに追加

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【ポジティブイラスト】
- 余白（背景の一部）に1〜2個追加
- 例：スキ（ハート）アイコン、グラフ上昇、星、いいねマーク、240スキの数字
- 明るくポジティブな雰囲気を演出
- タイトルの邪魔にならないように配置

【全体の雰囲気】
- 明るくポジティブ
- 祝福感、達成感のあるデザイン
- 親しみやすく温かみのある印象
- いつもの銘柄分析より華やか
- 読者への感謝が伝わる雰囲気

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## デザイン要素リスト

### 必須要素
1. **タイトル（左側、3段構成）**
   - 1段目：「note 活動振り返り」（小さめ）
   - 2段目：「1000PV突破！」（大きく、太字、明るく）
   - 3段目：「情報発信を続ける理由」（やや小さく）

2. **キャラクター（右下隅）**
   - アイヒモ（参考画像のスタイル維持）
   - 小さめサイズ、控えめに配置

3. **ポジティブイラスト（余白）**
   - スキ（ハート）アイコン
   - グラフ上昇のイメージ
   - 星やキラキラ
   - 「240スキ」の数字表示（オプション）

4. **背景**
   - 明るい色（ライトイエロー `#FFF9E6`、クリーム色 `#FFF8DC`、ライトオレンジ `#FFE5CC`）

### オプション要素（明るさを演出）
- 星やキラキラ（金色 `#FFD700`）を背景に散りばめる
- グラデーション背景（ライトイエロー → クリーム色）
- 「1000PV」や「240スキ」の数字を目立たせる

### 不要な要素
- 暗い色、重い色
- 複雑な図形
- ビジネスライクすぎるデザイン

## 使い方

1. **nanobananaにアクセス**: [https://www.nanobanana.com/](https://www.nanobanana.com/)
2. **参考画像をアップロード**: アイヒモのキャラクター画像を「参考画像」としてアップロード
3. **プロンプト入力**: 上記の日本語プロンプトまたは英語プロンプトをコピー&ペースト
4. **生成**: 画像を生成し、気に入ったものをダウンロード
5. **note記事に設定**: ダウンロードした画像をnote記事のヘッダー画像として設定

---

## 重要な注意事項

1. **参考画像は必須**
   アイヒモのキャラクター画像を必ず「参考画像」としてアップロードしてください。

2. **表情変更なし**
   アイヒモの表情は参考画像のイメージ通りに維持してください。

3. **明るい雰囲気を重視**
   このバナーはいつもの銘柄分析より明るく、ポジティブな雰囲気にしてください。背景色を明るくすることで、祝福感を演出します。

4. **イラストは1〜2個**
   余白にポジティブなイラスト（スキアイコン、グラフ、星など）を1〜2個追加してください。多すぎると煩雑になります。

5. **読みやすさを維持**
   明るい背景でもテキストが読みにくくならないよう、テキストカラーはダークグレーまたはネイビーを使用してください。

## カラーパレット（参考）

### 背景カラー（明るく）
- **ライトイエロー**: `#FFF9E6` または `#FFFACD`
- **クリーム色**: `#FFF8DC` または `#FFEFD5`
- **ライトオレンジ**: `#FFE5CC` または `#FFDAB9`

### テキストカラー（読みやすく）
- **ダークグレー**: `#2C3E50` または `#34495E`
- **ネイビー**: `#1A1A2E`

### アクセントカラー（明るく華やか）
- **明るいオレンジ**: `#FF9500` または `#FFA500`
- **ゴールド**: `#FFD700`
- **ライトグリーン**: `#90EE90` または `#98FB98`
- **ピンク（スキアイコン用）**: `#FF69B4`

## イラストの例

### 振り返り記事の場合
- **スキ（ハート）アイコン**: note のスキを表すハートマーク、ピンク色
- **グラフ上昇**: 右肩上がりのグラフ、1000PVを表現
- **星・キラキラ**: 達成感、祝福感を演出
- **数字「1000PV」「240スキ」**: 実績を視覚的に表示
- **いいねマーク（👍）**: ポジティブな反応のイメージ

**推奨**: スキアイコンとグラフ上昇の組み合わせが最も「振り返り」らしく、明るい雰囲気を演出しやすい。

## バリエーション案（必要に応じて）

もし複数のバナーパターンを試したい場合、以下の微調整を検討してください：

### パターンA：ライトイエロー背景（推奨）
- 背景：ライトイエロー（`#FFF9E6`）
- アクセント：オレンジ（`#FF9500`）、ゴールド（`#FFD700`）
- イラスト：スキアイコン（ピンク）、星（ゴールド）

### パターンB：クリーム色背景
- 背景：クリーム色（`#FFF8DC`）
- アクセント：ライトグリーン（`#90EE90`）、ゴールド（`#FFD700`）
- イラスト：グラフ上昇（グリーン）、星（ゴールド）

### パターンC：ライトオレンジ背景
- 背景：ライトオレンジ（`#FFE5CC`）
- アクセント：オレンジ（`#FF9500`）、ゴールド（`#FFD700`）
- イラスト：スキアイコン（ピンク）、数字「1000PV」（オレンジ）

**推奨**: パターンA（ライトイエロー背景）が最も明るくポジティブな印象を与えます。

## いつもの銘柄分析バナーとの違い

### 銘柄分析バナー（通常）
- 背景：白またはライトグレー
- 雰囲気：プロフェッショナル、シンプル
- イラスト：企業の事業内容（DNA、風力タービンなど）

### 振り返りバナー（今回）
- 背景：ライトイエロー、クリーム色、ライトオレンジ（明るい）
- 雰囲気：ポジティブ、祝福感、親しみやすい
- イラスト：スキアイコン、グラフ上昇、星など（達成感）

**ポイント**: 背景色を明るくすることで、いつもより華やかで温かみのある印象になります。
