# Google vs Nvidia AI株分析記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
GoogleとNvidiaのAI株競争を解説する記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 AI市場分析」（小さめ、カテゴリ表示）
  - 2段目：「GoogleがNvidiaを抜く！？」（大きく、太字）
  - 3段目：「AI株の勢力図が激変した理由」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：AI関連のイラスト（GoogleロゴとNvidiaロゴの対比、株価グラフ上昇など）

【デザイン要素】
- 背景：白またはライトブルーのシンプルな背景
- テキストカラー：ネイビーまたはダークグレー
- アクセント：Google系カラー（ブルー、レッド、イエロー、グリーン）とNvidia系（グリーン）を控えめに使用
- 装飾：最小限（線や複雑な図形は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【AI関連イラスト】
- 余白（背景の一部）に1つ追加
- 例：GoogleロゴとNvidiaロゴの対比、株価グラフ（上昇矢印）、AIチップ、Gemini 3ロゴ
- 控えめで、タイトルの邪魔にならないように配置
- AI株競争のテーマが視覚的に伝わるもの

【全体の雰囲気】
- シンプルでクリーン
- テック系でモダンな印象
- 装飾を控え、情報を明確に伝える
- AI株分析記事らしい先進的なデザイン

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## 企業イラストの例

### Google vs Nvidia の場合
- **GoogleロゴとNvidiaロゴの対比**：2つのロゴを並べて、競争を表現
- **株価グラフ（上昇矢印）**：Google株価の急上昇を表現
- **AIチップ**：AI半導体のイメージ、TPUやGPU
- **Gemini 3ロゴ**：Googleの新AIモデルを象徴
- **時価総額比較**：$3.9T vs $4.2Tの数字表示

**推奨**: GoogleロゴとNvidiaロゴの対比、または株価グラフ（上昇矢印）が最もAI株競争のテーマを表現しやすい。
