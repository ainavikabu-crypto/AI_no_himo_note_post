# Palantir Technologies 記事用バナー画像生成プロンプト

## 概要

この記事用のバナー画像は、**シンプルでミニマルなデザイン**を重視しています。装飾を最小限に抑え、タイトルとキャラクターに焦点を当てたクリーンなレイアウトです。

---

## nanobanana用プロンプト（日本語）

```
Palantir Technologies（PLTR）の米国株投資分析を紹介するnote記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（2段構成）
  - 1段目：「Palantir Technologies (PLTR)」（大きく、太字）
  - 2段目：「防衛とAI、2つの顔を持つデータ企業」（やや小さく）
- 右側：アイヒモのキャラクター（肩より上のバストショット）

【デザイン要素】
- 背景：白またはライトグレーのシンプルな背景
- テキストカラー：ネイビーまたはダークグレー
- アクセント：Palantirのブランドカラー（ダークブルー）を控えめに使用
- 装飾：最小限（線や図形などの装飾は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右側に配置、肩より上のバストショット
- 背景に自然に溶け込むように配置

【全体の雰囲気】
- シンプルでクリーン
- プロフェッショナルで読みやすい
- 装飾を控え、情報を明確に伝える

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## デザイン要素リスト（シンプル版）

### 必須要素
1. **タイトル（左側）**
   - 1段目：「Palantir Technologies (PLTR)」
   - 2段目：「防衛とAI、2つの顔を持つデータ企業」

2. **キャラクター（右側）**
   - アイヒモ（参考画像のスタイル維持）

3. **背景**
   - シンプルな単色背景（白またはライトグレー）

### オプション要素（最小限）
- Palantirのブランドカラー（ダークブルー）をアクセントとして控えめに使用
- タイトルとキャラクターの間に余白を十分に確保

### 不要な要素
- 複雑な図形やパターン
- 過度なグラデーション
- 多色使い
- 装飾的なラインやフレーム

## 使い方

1. **nanobananaにアクセス**: [https://www.nanobanana.com/](https://www.nanobanana.com/)
2. **参考画像をアップロード**: アイヒモのキャラクター画像を「参考画像」としてアップロード
3. **プロンプト入力**: 上記の日本語プロンプトまたは英語プロンプトをコピー&ペースト
4. **生成**: 画像を生成し、気に入ったものをダウンロード
5. **note記事に設定**: ダウンロードした画像をnote記事のヘッダー画像として設定

---

## 重要な注意事項

1. **参考画像は必須**
   アイヒモのキャラクター画像を必ず「参考画像」としてアップロードしてください。参考画像がないと、キャラクターのスタイルが一貫しません。

2. **表情変更なし**
   アイヒモの表情は参考画像のイメージ通りに維持してください。明るくしたり、変更したりしないでください。

3. **シンプルさを重視**
   このバナーは装飾を最小限に抑えたシンプルなデザインです。複雑な要素を追加しないでください。

4. **複数パターン生成**
   一度に複数のバリエーションを生成し、最も読みやすくシンプルなものを選んでください。

## カラーパレット（参考）

### メインカラー
- **テキスト**: `#2C3E50`（ダークグレー）または `#1A1A2E`（ネイビー）
- **背景**: `#FFFFFF`（ホワイト）または `#F5F5F5`（ライトグレー）

### アクセントカラー（控えめに使用）
- **Palantir ブランドカラー**: `#0A2540`（ダークブルー）

---

## バリエーション案（必要に応じて）

もし複数のバナーパターンを試したい場合、以下の微調整を検討してください：

### パターンA：完全ミニマル
- 背景：完全な白（`#FFFFFF`）
- テキスト：ダークグレー（`#2C3E50`）
- アクセント：なし

### パターンB：ブランドカラー強調
- 背景：ライトグレー（`#F5F5F5`）
- テキスト：ダークブルー（`#0A2540`）
- アクセント：タイトル下に細いラインを追加（ダークブルー）

### パターンC：グレーベース
- 背景：ライトグレー（`#F5F5F5`）
- テキスト：ネイビー（`#1A1A2E`）
- アクセント：なし

**推奨**: パターンA（完全ミニマル）が最もシンプルで読みやすいです。
