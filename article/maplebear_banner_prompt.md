# Maplebear（CART）記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
Maplebear（CART）の米国株投資分析を紹介するnote記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 銘柄分析」（小さめ、カテゴリ表示）
  - 2段目：「Maplebear (CART)」（大きく、太字）
  - 3段目：「Instacart運営、広告収益$1.45Bで急成長」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：企業の事業内容を表すイラスト（Instacartロゴ、スマホアプリ、食品配達など）

【デザイン要素】
- 背景：白またはライトグレーのシンプルな背景
- テキストカラー：ネイビーまたはダークグレー
- アクセント：Instacartブランドカラー（グリーン、オレンジ）を控えめに使用
- 装飾：最小限（線や複雑な図形は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【企業イラスト】
- 余白（背景の一部）に1つ追加
- 例：Instacartロゴ、スマホアプリ画面、食品配達ボックス、ショッピングカート
- 控えめで、タイトルの邪魔にならないように配置
- Maplebear/Instacartの事業（食品宅配）が視覚的に伝わるもの

【全体の雰囲気】
- シンプルでクリーン
- プロフェッショナルで読みやすい
- 装飾を控え、情報を明確に伝える
- 食品宅配サービスらしい親しみやすい印象

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## 企業イラストの例

### Maplebear (Instacart) の場合
- **Instacartロゴ**：緑とオレンジのブランドカラー
- **スマホアプリ画面**：食品検索画面、カート画面
- **食品配達ボックス**：配達用の紙袋、食品ボックス
- **ショッピングカート**：オンラインショッピングカートのアイコン
- **食品アイコン**：野菜、果物、食材のイラスト

**推奨**: スマホアプリ画面または食品配達ボックスが最もInstacartのビジネス（食品宅配）を表現しやすい。
