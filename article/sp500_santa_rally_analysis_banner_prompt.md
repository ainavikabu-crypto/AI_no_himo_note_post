# S&P500サンタラリー分析記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
S&P500のサンタラリー（年末株価上昇）を解説する記事のバナー画像を作成してください。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 市場分析」（小さめ、カテゴリ表示）
  - 2段目：「S&P500史上最高値まで0.78%！」（大きく、太字）
  - 3段目：「サンタラリーは来るのか徹底検証」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：株式市場に関連するイラスト（上昇する株価チャート、サンタ帽子を被ったチャート、史上最高値を示す矢印など）

【デザイン要素】
- 背景：白またはライトグリーンのシンプルな背景（上昇・ポジティブな印象）
- テキストカラー：ダークグレーまたはネイビー
- アクセント：グリーン（上昇）、レッド（サンタ）を控えめに使用
- 装飾：最小限（線や複雑な図形は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【株式市場イラスト】
- 余白（背景の一部）に1つ追加
- 例：上昇する株価チャート（ローソク足またはライン）、史上最高値を示す上向き矢印、サンタ帽子を被ったチャート、年末カレンダーとチャートの組み合わせ
- 控えめで、タイトルの邪魔にならないように配置
- サンタラリー（年末株価上昇）のテーマが視覚的に伝わるもの

【全体の雰囲気】
- シンプルでクリーン
- ポジティブで期待感のあるデザイン
- 装飾を控え、情報を明確に伝える
- 市場分析記事らしい専門的な印象
- 年末のホリデーシーズンの雰囲気も少し感じられる

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## 企業イラストの例

### S&P500サンタラリーの場合
- **上昇する株価チャート（グリーン）**：右肩上がりのローソク足チャート、上昇トレンドライン
- **史上最高値を示す矢印**：チャートの上に大きな上向き矢印、「ATH」（All-Time High）のラベル
- **サンタ帽子を被ったチャート**：株価チャートにサンタ帽子を組み合わせ、サンタラリーを表現
- **年末カレンダーとチャート**：12月カレンダーと上昇チャートの組み合わせ
- **S&P500ロゴ**：S&P500の公式ロゴまたは「SPX」の文字

**推奨**: 上昇する株価チャート（グリーン）にサンタ帽子を組み合わせたイラストが最もサンタラリーのテーマを表現しやすい。
