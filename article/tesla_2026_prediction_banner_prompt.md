# Tesla 2026年予測記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
Teslaの2026年株価予測を解説する記事のバナー画像を作成してください。アナリスト予想が真っ二つに分かれている状況を表現します。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 銘柄分析」（小さめ、カテゴリ表示）
  - 2段目：「Tesla 2026年予測」（大きく、太字）
  - 3段目：「上がる？下がる？アナリスト真っ二つ」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：Teslaに関連するイラスト（Tesla車両、上下矢印、FSD自動運転のイメージなど）

【デザイン要素】
- 背景：白またはライトグレーのシンプルな背景
- テキストカラー：ダークグレーまたはネイビー
- アクセント：グリーン（上昇）とレッド（下落）を対比的に使用して「予想が分かれている」感を表現
- 装飾：最小限（線や複雑な図形は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【Teslaイラスト】
- 余白（背景の一部）に1つ追加
- 例：Tesla車両（Model 3/Y/S/X）のシルエット、上向き矢印と下向き矢印の対比、FSD自動運転のステアリングマーク、ロボタクシーのイメージ、株価チャートの上下変動
- 控えめで、タイトルの邪魔にならないように配置
- 「予想が分かれている」「不確実性」のテーマが視覚的に伝わるもの

【全体の雰囲気】
- シンプルでクリーン
- 予想の不確実性を表現（上昇と下落の両方の可能性）
- 装飾を控え、情報を明確に伝える
- 投資判断が難しい状況を示唆するデザイン
- 対立・分裂の印象（グリーンとレッドの対比）

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## 企業イラストの例

### Tesla 2026年予測の場合
- **上下矢印の対比**：Tesla車両またはロゴを中心に、上向き矢印（グリーン）と下向き矢印（レッド）を配置
- **Tesla車両（Model 3/Y）**：シルエットまたはシンプルなイラスト、Teslaのアイコニックなデザイン
- **FSD自動運転マーク**：ステアリングホイールに手を触れていないイメージ、自動運転の象徴
- **ロボタクシー**：無人のTesla車両、未来的なイメージ
- **分裂した株価チャート**：一つのチャートが上昇と下落に分岐するイメージ

**推奨**: 上下矢印の対比（グリーンとレッド）がアナリスト予想が真っ二つに分かれている状況を最も明確に表現できる。Tesla車両のシルエットを中心に配置し、その上下に矢印を追加するデザインが効果的。

## カラーパレット（参考）

### メインカラー
- **テキスト**: `#2C3E50`（ダークグレー）または `#1A1A2E`（ネイビー）
- **背景**: `#FFFFFF`（ホワイト）または `#F5F5F5`（ライトグレー）

### アクセントカラー（対比的に使用）
- **上昇グリーン**: `#27AE60` または `#2ECC71`
- **下落レッド**: `#E74C3C` または `#C0392B`
- **Tesla（ブランドカラー）**: `#E82127`（Teslaレッド）または `#000000`（ブラック）

### 対比の表現
- グリーンとレッドを左右または上下に配置して、予想の分裂を視覚化
- 中央のTesla車両は中立色（ブラックまたはグレー）
