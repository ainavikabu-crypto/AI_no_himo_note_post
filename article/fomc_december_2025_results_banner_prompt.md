# FOMC 2025年12月結果速報記事用バナー画像生成プロンプト

## nanobanana用プロンプト（日本語）

```
FRBのFOMC会議結果（2025年12月）を速報解説する記事のバナー画像を作成してください。「タカ派的カット」をテーマにします。

【レイアウト】
- 左側：タイトルテキスト（3段構成）
  - 1段目：「米国株 市場分析」（小さめ、カテゴリ表示）
  - 2段目：「FOMC速報解説」（大きく、太字）
  - 3段目：「タカ派的カットで株価急落のワケ」（やや小さく）
- 右下隅：アイヒモのキャラクター（小さめ、肩より上のバストショット）
- 余白：FOMCに関連するイラスト（FRBビル、金利グラフ、下向き矢印など）

【デザイン要素】
- 背景：白またはライトイエローのシンプルな背景（速報感）
- テキストカラー：ダークグレーまたはネイビー
- アクセント：レッド（警告、急落）とオレンジ（注意）を使用
- 装飾：最小限（線や複雑な図形は不要）

【キャラクター：アイヒモ】
- 参考画像のスタイルをそのまま維持（表情変更なし）
- 右下隅に小さめに配置（タイトルの邪魔にならないサイズ）
- 肩より上のバストショット

【FOMCイラスト】
- 余白（背景の一部）に1つ追加
- 例：FRBビル（Federal Reserve Building）、下向き矢印（株価急落）、金利グラフ（横ばい〜緩やかな下降）、「-0.25%」の表記、パウエル議長のシルエット
- 控えめで、タイトルの邪魔にならないように配置
- 「タカ派的カット」「慎重姿勢」のテーマが視覚的に伝わるもの

【全体の雰囲気】
- シンプルでクリーン
- 速報感、緊急性を表現
- 装飾を控え、情報を明確に伝える
- 慎重・警告のニュアンス（レッド・オレンジのアクセント）
- ニュース速報らしい専門的な印象

【サイズ】
- 横長バナー（16:9または類似の比率）
- note記事のヘッダーに適したサイズ
```

## 企業イラストの例

### FOMC速報の場合
- **FRBビル（Federal Reserve Building）**：ワシントンD.C.のFRB本部ビルのシルエット
- **下向き矢印（レッド）**：株価急落を表現、金利グラフと組み合わせ
- **金利グラフ**：横ばい〜緩やかな下降、「3.5%-3.75%」の表記
- **「-0.25%」の表記**：利下げ幅を明確に示す
- **パウエル議長のシルエット**：記者会見のイメージ、マイクの前に立つ姿

**推奨**: FRBビルのシルエットと下向き矢印（レッド）の組み合わせが、FOMC結果と株価急落を最も明確に表現できる。または金利グラフ（横ばい）に「タカ派的」のニュアンスを示す。

## カラーパレット（参考）

### メインカラー
- **テキスト**: `#2C3E50`（ダークグレー）または `#1A1A2E`（ネイビー）
- **背景**: `#FFFFFF`（ホワイト）または `#FFF9E6`（ライトイエロー、速報感）

### アクセントカラー（警告・注意）
- **警告レッド**: `#E74C3C` または `#C0392B`
- **注意オレンジ**: `#F39C12` または `#E67E22`
- **FRB（ブランドカラー）**: `#0C3C60`（ダークブルー）または `#1A5490`

### 速報感の表現
- ライトイエロー背景で緊急性を演出
- レッドの下向き矢印で株価急落を強調
- オレンジで「注意が必要」のニュアンス
